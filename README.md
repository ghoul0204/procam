# 專業相機 ProCam

為 Pixel 8 Pro 打造、「邊拍邊學」的手動相機。

## 功能
- 手動 ISO、快門（1/8000～30 秒）、對焦、白平衡、曝光補償
- 只手動其中一項時自動補另一項：快門優先 (S)、ISO 優先；兩項都手動就是全手動 (M)，會顯示測光表
- 即時直方圖（含過曝／死黑警示）、斑馬紋、峰值對焦、三分構圖線、水平儀
- 0.5x / 1x / 2x / 5x / 10x 鏡頭切換、雙指縮放
- 點畫面對焦＋測光並鎖定，長按解除
- RAW (DNG) ＋ JPEG，存在 相簿 → DCIM/ProCam
- 3 / 10 秒自拍計時、音量鍵當快門
- 每個參數都有白話解說、即時「教練提示」、內建攝影課本與 8 週練習作業
